# Classic Computer Science Problems in Python

This repository contains my personal solutions, notes, and implementations for exercises from the book **[*Classic Computer Science Problems in Python*](https://www.manning.com/books/classic-computer-science-problems-in-python)** by David Kopec.

The goal of this repository is to strengthen my understanding of core algorithms, data structures, and problem-solving techniques while applying modern Python practices (type hinting, unit testing, and clear code documentation).
